# LangChain Components

## Overview

LangChain's power comes from how its components work together to create sophisticated AI applications. This document describes the relationships between the main components.

## Core Component Ecosystem

LangChain's major components connect to form complete AI applications. Each component layer builds on the previous ones.

The main stages are:

1. **Input processing:** Transform raw data into structured documents.
2. **Embedding and storage:** Convert text into searchable vector representations.
3. **Retrieval:** Find relevant information based on user queries.
4. **Generation:** Use AI models to create responses, optionally with tools.
5. **Orchestration:** Coordinate the application through agents and memory systems.
